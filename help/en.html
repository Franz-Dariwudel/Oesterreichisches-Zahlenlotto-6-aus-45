Startup and requirements

Linux Mint, Python 3.12, GTK 4, PyGObject/Pycairo and Poppler. Matplotlib is required for charts and is included in the installable package. Launch through the desktop/menu entry or python3 -B -m lotto45. File → Quit exits. Startup creates a missing empty database, checks integrity and extends the schema only after backup. Problems show an error code and remedy. config/settings.json selects the active database.

Menus and archive

Lotto 6 out of 45 and Joker have separate latest draws, date search, number search, odds, statistics and tips. Shared contains inventory, review notes, data checks, sources, import log, local imports, backup, restore and diagnostics. Dates show their calculated weekday. Date search accepts DD.MM.YYYY, MM.YYYY, YYYY and partial input; weekday and draw type further narrow results. Lotto number filters consider main numbers only. Odds preserve zero, unknown amounts, ATS/EUR and jackpots.

Check for new data

The button or Shared → Update and check data uses the saved source selection. The report lists unchanged files, changes, notes and failures. Reimporting does not duplicate rounds. Game, date and identifier identify a round; the same numbers can occur on different days. Critical parser errors roll back the affected file. Conflicts remain in review notes; CLI --allow-corrections explicitly enables correction.

Manage and check sources

Shared → Download opens source management. Edit name, URL, game, format, priority and activation; lower priority is processed first. Defaults are in resources/default_sources.json; overrides in config/download_sources.json. Existing selection and changed URLs are preserved. Missing defaults are added disabled. New installations enable official sources; third-party archives remain optional and disabled. Check sources fetches a sample and verifies parser structure. CSV/PDF must match supported yearly/archive formats, not arbitrary tables. Yearly filenames include the year.

Temporary files and logs

Archive downloads and PDF staging use own /tmp directories and are removed after success/failure. Active locked directories and unrelated files are preserved; marked orphan directories are removed at startup. Rejected raw files are retained permanently at data/rejected/<sha256>.bin for diagnosis. The database import log persists. logs/error.log starts fresh each session; --help and --version leave it unchanged. Language downloads use an own temporary subdirectory in the user Downloads folder.

Statistics and charts

Choose Statistics within a game menu. Calendar start/end (YYYY-MM-DD), weekday (-1 all, 0 Monday to 6 Sunday), draw type and last N work together; Refresh applies the inputs. Calendar filters are applied before last N. Select the past year using From/To. Lotto includes frequencies, gaps, pairs/triples, sums, parity, repeats and patterns. Additional patterns cover primes, birthday numbers, mirror pairs, decades, arithmetic gaps and quantiles. Rolling charts use up to 20 draws per point. Z-score is a standardized deviation; chi-square is descriptive without a p-value.

Joker analysis

Joker preserves leading zeros and the order of all six positions. Patterns and distributions include position frequencies, digit sum, E/O parity, distinct/repeated digits, equal neighbours, longest run, symmetry (0–3), palindromes, transitions, suffixes, Shannon entropy in bits and weekday comparisons. Weekday heatmaps contain absolute frequencies and depend on the number of draws per weekday. E = even, O = odd.

Chart display

Matplotlib draws locally using system fonts and colors. Charts state the period, sample size and filters. Draw, statistics and chart exports are not available. Tips can be saved as CSV or printed. On X11 the application defaults to Cairo without DRI3; an explicit GSK_RENDERER choice is respected.

Create tips

Choose Create tips within the game menu and enter a positive count. The default limit is 10,000; Edit → Settings permits 1 to 1,000,000. Pure random is always available without filters. Statistically filtered displays individually enabled rules directly. Set values in the corresponding statistics page under Configure tip filters; tip creation only provides activation checkboxes. Enter minimum/maximum separated by a comma, for example 2,4. Weight -5 favours rare, +5 frequent and 0 is neutral. SystemRandom is the normal random generator. Each Lotto combination is sorted with six distinct numbers; Joker is six-digit text. There are no duplicates within a batch.

Lotto filters

Sum range or historical quantiles 0–100%, even numbers, numbers 1–22, longest consecutive run, repeats from the last selected draw, minimum range, primes, numbers 1–31, exact decade occupancy (five counts summing to 6) and pair preference. Unusual permits sums <80 or >=190, six even/odd numbers or runs of at least four. Weights are selection preferences, not predictions.

Joker filters

Position weights, sum 0–54, distinct digits 1–6, longest adjacent run, maximum occurrences of a digit anywhere, palindrome allow/avoid/only and preference for the last two digits. Historical rules require draws within the selected period. Strict rules stop after bounded attempts with L012 and rejection counts.

Profiles, history and printing

Enter a profile name and save; load/delete through the form or Profile menu. Lotto and Joker profiles are separate. Loading/saving sets the selected CLI profile. Each batch stores an independent full profile snapshot, timestamp and RNG mode. History displays previous batches in pages. Print opens the GTK system dialog. Tip history is retained. Tip batches can be saved as CSV. Import Joker columns as text in spreadsheets to preserve leading zeros.

Backup, diagnostics and restore

Shared → Back up database uses SQLite backup and requires a new destination. Check database verifies integrity and foreign keys. A schema extension first creates an automatic backup in data/backups/. Damaged originals are never overwritten. Restore checks the source, copies into a new file and activates it only after success. Diagnostics contains version, schema, checks and import/source status without computer paths or raw data. New archives do not build millions of combination entries; existing catalogs remain.

Languages and help

Project source: Franz-Dariwudel/Oesterreichisches-Zahlenlotto-6-aus-45. Enter a language code. Only missing language and help files are installed; active downloads continue after closing this dialog.

Configure tip filters in statistics

Set sums/quantiles in Sums, even/low numbers in Parity/Low-high, runs in Neighbors, repeats in Repeats, span in Ranges, pair preference in Pairs and weighting in Numbers. Other Lotto rules are in Patterns. For Joker, weighting is in Joker statistics and other rules in Patterns. Open Configure tip filters, edit values and save. Tip creation only enables rules with checkboxes. The reference period is shared within each game and independent of the statistics display period. Values are stored under tip_rule_settings in config/settings.json. Loading a profile applies its values to these settings; earlier tip batches retain their snapshots. The Kind column is hidden until the entire game archive contains a value other than the main draw; refresh or reopen the view to recheck.

Command line

python3 -B -m lotto45 --help
python3 -B -m lotto45 --tips 12 --game lotto
python3 -B -m lotto45 --tips 12 --game joker --profile
python3 -B -m lotto45 --tips 12 --game lotto --profile MyProfile
python3 -B -m lotto45 --db /path/test.sqlite3 --tips 6 --game joker --seed 42
python3 -B -m lotto45 --download
python3 -B -m lotto45 --stats patterns --game joker --last 100
python3 -B -m lotto45 --stats charts --chart zscore --stats-number 17 --from-date 2025-01-01
python3 -B -m lotto45 --backup /path/new-backup.sqlite3
python3 -B -m lotto45 --diagnose
python3 -B -m lotto45 --summary --check

--profile without a name executes the saved selected profile. If missing, the action fails rather than using another profile. --seed is exclusively test mode. --generate optionally builds the full universe and is unnecessary for normal use. Exit codes: 0 success, 1 operation failure, 2 argument error.

Source and installation

Complete Python source and installable Python 3.12 bytecode are delivered separately. python3 install.py installs desktop and menu launchers; python3 install.py --uninstall removes unchanged journaled files, preserves later user data and reports retained files. See --help for --prefix, --desktop-dir and --menu-dir. README.md describes requirements and building. Licenses: LICENSE and THIRD_PARTY.md.

Invalid tip filter settings in config/settings.json are reported as L004 and are not overwritten; check tip_rule_settings for the affected game. Failed writes preserve the previous settings.

Date fields have an adjacent calendar. DD.MM.YYYY, including single-digit days/months, and YYYY-MM-DD are accepted; dates are stored in ISO format. Empty fields do not constrain the period.

Switching between Lotto and Joker retains the current menu page where available. Tip creation and tip history remain separate views. Patterns is available for both games. Lotto-specific statistics switch to Joker statistics; switching back restores the last Lotto statistics page.

Draw type fields, like the Kind column, are shown only when the game archive contains another kind. Reopen the view or refresh statistics after importing. Frequency charts scale their axes automatically; 500 is not a cap. The All period includes every stored draw.

Frequency charts show the actual maximum count in the title and on the vertical axis. A dotted line marks that value. Changing the period updates both maximum and scale.

All charts show the maximum of the analysed data in the title. Bar and line charts add a value-axis tick and guide line. Heatmaps show the maximum on a color scale and outline cells with that value. Reference lines are excluded from the data maximum. Empty charts do not show a maximum.

Inventory uses tabs for Lotto/Joker, sources and table details. Complete catalogs show the combination count once; incomplete catalogs show stored out of possible. Download sources and result details use Previous and Next without scrollbars. Edits survive page changes; Save stores all sources.

For win2day and GitHub sources, the original website logo appears on the right, selected by URL. Unknown providers show no logo. If the local image cannot be read (L001), downloading remains available; restore the corresponding image in resources/site-logos from the application package.

Shared → Update and check data combines downloading new data, checking database integrity and creating a diagnostic report. Reports are saved automatically under logs/ with a timestamp; the result shows their location. Individual errors do not prevent subsequent checks. Cancel stops the workflow. For write errors (L001), check permissions and free space in the logs folder.

All four steps are visible from the start, each with its own status. Live download details appear below. A check mark is shown only after that step completes successfully; the diagnostic step also requires saving the report.

The combined workflow starts with “Check sources”, verifying availability and data structure of enabled sources. Data retrieval, database validation and the diagnostic report follow. All four steps have their own status row. Source failures appear in the result and report; subsequent checks still run.

The 6 aus 45 application logo appears to the right of the check steps. If the image is missing or damaged (L001), checks remain available; restore resources/logo-6aus45-v1.png from the application package.
