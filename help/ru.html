Файл → Выход

Закрывает приложение и запрашивает отмену запущенных фоновых задач. Завершите важную работу первым; активный сетевой запрос может остановиться до истечения времени истечения.

Редактировать → Настройки

Выберите язык интерфейса, максимальное количество лотерейных комбинаций и проект GitHub, используемый для загрузки языков. Сохранить, чтобы применить настройки. Языковые файлы обнаруживаются снова, когда открывается это окно. В области загрузки устанавливаются отсутствующие языковые файлы и файлы справки без замены существующих файлов.

Lotto 6 из 45 → Последние тиражи

Показывает последний сохраненный розыгрыш лотереи для этой игры с номерами и доступными призами. Это локальный архив, а не прямая трансляция результатов. Используйте общее обновление и проверьте рабочий процесс для получения новых данных.

Lotto 6 из 45 → Тиражи по дате

Поиск сохраненных розыгрышей лотереи по дате. Введите день, месяц или год или воспользуйтесь календарем. Объедините фильтры по дате и номерам, а затем выполните поиск. Перемещайтесь между страницами результатов; дополнительные типы розыгрышей лотереи предлагаются только при их наличии в архиве.

Lotto 6 из 45 → Поиск выпавших чисел

Найдите фактически выпавшие комбинации, а также даты их розыгрыша. Введите основные номера Lotto или цифры Joker и начните поиск. Просмотрите страницы результатов или введите номер страницы. При этом осуществляется поиск по зарегистрированным тиражам лотерей, а не по каталогу всех возможных лотерейных комбинаций.

Lotto 6 из 45 → Суммы призов

Исходные валюты и информация о джекпоте сохраняются. Фиксированные призы Joker могут быть дополнены в соответствии с действующими историческими правилами.

Lotto 6 из 45 → Создать комбинации

Успешные пакеты сохраняются со своими настройками. Ограничительные правила могут вызвать ошибку L012; ослабить правила или сократить количество. Исторические закономерности не улучшают шансы на выигрыш.

Общие функции → Обновите и проверьте данные

Запуск и требования

Linux Mint, Python 3.12, GTK 4, PyGObject/Pycairo и Poppler. Matplotlib необходим для диаграмм и включен в устанавливаемый пакет. Запускаем через запись desktop/menu или python3 -B -m лото45. Файл → Выход. Автозагрузка создает недостающую пустую базу данных, проверяет целостность и расширяет схему только после резервного копирования. Проблемы показывают код ошибки и способ устранения. config/settings.json выбирает активную базу данных.

Меню и архив

Lotto 6 из 45 и Joker имеют отдельные последние розыгрыши лотереи, поиск по дате, поиск по номеру, шансы, статистику и лотерейные комбинации. Общий содержит инвентаризацию, заметки к обзору, проверки данных, источники, журнал импорта, локальный импорт, резервное копирование, восстановление и диагностику. Даты показывают расчетный день недели. Поиск по дате принимает DD.MM.YYYY, MM.YYYY, YYYY и частичный ввод; будние дни и тип розыгрыша лотереи еще больше сужают результаты. Числовые фильтры Lotto учитывают только основные номера. Коэффициенты сохраняют ноль, неизвестные суммы, ATS/EUR и джекпоты.

Проверьте наличие новых данных

Кнопка или Общие функции → Обновите и проверьте данные использует сохраненный выбор источника. В отчете перечислены неизмененные файлы, изменения, примечания и сбои. Реимпорт не дублирует раунды. Игра, дата и идентификатор идентифицируют раунд; одни и те же числа могут встречаться в разные дни. Критические ошибки парсера откатывают затронутый файл. Конфликты остаются в обзорных заметках; CLI --allow-corrections явно разрешает исправление.

Управление и проверка источников

Общий → Загрузка открывает управление исходным кодом. Редактировать имя, URL-адрес, игру, формат, приоритет и активацию; сообщения с более низким приоритетом обрабатываются в первую очередь. По умолчанию находятся в resources/default_sources.json; переопределения в config/download_sources.json.. Существующий выбор и измененные URL-адреса сохраняются. Отсутствующие значения по умолчанию добавляются отключенными. Новые установки позволяют использовать официальные источники; сторонние архивы остаются необязательными и отключенными. Проверка источников извлекает образец и проверяет структуру парсера. CSV/PDF должен соответствовать поддерживаемым форматам yearly/archive, а не произвольным таблицам. Ежегодные имена файлов включают год.

Временные файлы и журналы

Загрузки архива и промежуточная версия PDF используют собственные каталоги /tmp и удаляются после success/failure.. Активные заблокированные каталоги и несвязанные файлы сохраняются; помеченные потерянные каталоги удаляются при запуске. Отклоненные необработанные файлы постоянно сохраняются по адресу data/rejected/.<ша256>.bin для диагностики. Журнал импорта базы данных сохраняется. logs/error.log начинает каждый сеанс заново; --help и --version оставляют его без изменений. Языковые загрузки используют собственный временный подкаталог в папке «Загрузки пользователя».

Статистика и графики

Выберите «Статистика» в меню игры. Календарь start/end (YYYY-MM-DD), день недели (-1 все, 0 с понедельника по 6 воскресенья), тип розыгрыша лотереи и последний N работают вместе; Обновить применяет входные данные. Календарные фильтры применяются перед последним N. Выберите прошлый год с помощью From/To.. Lotto включает частоты, пробелы, pairs/triples, суммы, четность, повторы и шаблоны. Дополнительные шаблоны охватывают простые числа, числа дней рождения, зеркальные пары, десятилетия, арифметические пробелы и квантили. В скользящих диаграммах используется до 20 лотерейных розыгрышей на точку. Z-показатель представляет собой стандартизированное отклонение; Хи-квадрат носит описательный характер без p-значения.

Joker анализ

Joker сохраняет ведущие нули и порядок всех шести позиций. Шаблоны и распределения включают частоты позиций, сумму цифр, четность E/O, цифры distinct/repeated, равных соседей, самый длинный период, симметрию (0–3), палиндромы, переходы, суффиксы, энтропию Шеннона в битах и ​​сравнения дней недели. Тепловые карты будних дней содержат абсолютные частоты и зависят от количества розыгрышей лотереи в будний день. E = четный, O = нечетный.

Отображение диаграммы

Matplotlib рисует локально, используя системные шрифты и цвета. На диаграммах указан период, размер выборки и фильтры. Рисование, статистика и экспорт диаграмм недоступны. лотерейные комбинации можно сохранить как CSV или распечатать. В X11 приложение по умолчанию использует Cairo без DRI3; учитывается явный выбор GSK_RENDERER.

Создавайте лотерейные комбинации

Выберите «Создать лотерейные комбинации» в меню игры и введите положительный результат. Лимит по умолчанию — 10 000; Редактировать → Настройки разрешают от 1 до 1 000 000. Чистый рандом всегда доступен без фильтров. Статистическая фильтрация напрямую отображает индивидуально активированные правила. Установите значения на соответствующей странице статистики в разделе «Настроить фильтры комбинаций лотерейных билетов»; при создании лотерейной комбинации предусмотрены только флажки активации. Введите minimum/maximum через запятую, например 2,4. Вес -5 означает редкость, +5 - частость, а 0 - нейтральность. SystemRandom — обычный генератор случайных чисел. Каждая комбинация Lotto сортируется по шести различным числам; Joker — шестизначный текст. В пакете нет дубликатов.

Фильтры Lotto

Диапазон сумм или исторические квантили 0–100 %, четные числа, числа 1–22, самая длинная последовательная серия, повторы из последнего выбранного тиража лотереи, минимальный диапазон, простые числа, числа 1–31, точная занятость в десятилетии (пять отсчетов в сумме дают 6) и предпочтение пары. Необычные суммы разрешений<80 или>=190, шесть чисел even/odd или серии из не менее четырех. Веса — это предпочтения выбора, а не прогнозы.

Фильтры Joker

Веса позиций, сумма 0–54, отдельные цифры 1–6, самая длинная соседняя серия, максимальное количество вхождений цифры в любом месте, палиндром allow/avoid/only и предпочтение последних двух цифр. Исторические правила требуют розыгрышей лотереи в течение выбранного периода. Строгие правила прекращаются после ограниченного количества попыток с L012 и количества отклонений.

Профили, история и печать

Введите имя профиля и сохраните; load/delete через форму или меню «Профиль». Профили Lotto и Joker являются отдельными. Loading/saving устанавливает выбранный профиль CLI. В каждом пакете хранится независимый снимок полного профиля, временная метка и режим RNG. В истории отображаются предыдущие партии на страницах. Печать открывает системное диалоговое окно GTK. История лотерейных комбинаций сохраняется. Пакеты лотерейных комбинаций можно сохранить как CSV. Импортируйте столбцы Joker как текст в электронные таблицы, чтобы сохранить ведущие нули.

Резервное копирование, диагностика и восстановление

Общий → База данных резервного копирования использует резервную копию SQLite и требует нового места назначения. Проверка базы данных, проверка целостности и внешних ключей. Расширение схемы сначала создает автоматическую резервную копию в data/backups/.. Поврежденные оригиналы никогда не перезаписываются. Восстановление проверяет источник, копирует в новый файл и активирует его только в случае успеха. Диагностика содержит версию, схему, проверки и статус import/source без путей к компьютеру или необработанных данных. Новые архивы не создают миллионы комбинированных записей; существующие каталоги остаются.

L013Операция отмененаНеполная партия лотерейных комбинаций не сохраняется. Ранее завершенный импорт отдельных архивов остается действительным; операцию можно возобновить. Текущий HTTP-вызов завершается не позднее истечения времени ожидания сети.
L014Вывод файла не удалсяПроверьте лотерейную комбинацию CSV, место назначения резервного копирования или диагностики и разрешения на запись. Существующие файлы назначения сохраняются в случае сбоя.

Исходный код и установка

Полный исходный код Python и устанавливаемый байт-код Python 3.12 поставляются отдельно. python3 install.py устанавливает средства запуска рабочего стола и меню; python3 install.py --uninstall удаляет неизмененные журнальные файлы, сохраняет более поздние пользовательские данные и сообщает о сохраненных файлах. См. --help для --prefix, --desktop-dir и --menu-dir. README.md описывает требования и сборку. Лицензии: LICENSE и THIRD_PARTY.md.

Неверные настройки фильтра комбинации лотереи в config/settings.json обозначаются как L004 и не перезаписываются; проверьте Tip_rule_settings для затронутой игры. При неудачной записи предыдущие настройки сохраняются.

Поля даты имеют соседний календарь. Принимаются DD.MM.YYYY, включая однозначные days/months и YYYY-MM-DD; даты хранятся в формате ISO. Пустые поля не ограничивают период.

При переключении между Lotto и Joker сохраняется текущая страница меню, если она доступна. Создание лотерейных комбинаций и история лотерейных комбинаций остаются отдельными представлениями. Шаблоны доступны для обеих игр. Статистика, специфичная для Lotto, переключается на статистику Joker; переключение назад восстанавливает последнюю страницу статистики Lotto.

Поля типа розыгрыша лотереи, такие как столбец «Вид», отображаются только в том случае, если в игровом архиве есть другой вид. Повторно откройте просмотр или обновите статистику после импорта. Частотные диаграммы автоматически масштабируют свои оси; 500 это не предел. Период «Все» включает в себя каждый сохраненный тираж лотереи.

Диаграммы частот показывают фактическое максимальное количество в заголовке и на вертикальной оси. Это значение отмечено пунктирной линией. Изменение периода обновляет как максимум, так и масштаб.

Все графики показывают в заголовке максимум анализируемых данных. На гистограммах и линейных диаграммах добавляются отметка оси значений и направляющая линия. Тепловые карты показывают максимум на цветовой шкале и выделяют ячейки с этим значением. Опорные линии исключаются из максимума данных. Пустые графики не показывают максимум.

В инвентаре используются вкладки для Lotto/Joker, источников и сведений о таблицах. В полных каталогах количество комбинаций указывается один раз; Неполные каталоги показывают сохраненные из возможных. Источники загрузки и сведения о результатах используют «Предыдущий» и «Далее» без полос прокрутки. Редактирование сохраняется при изменении страницы; Save сохраняет все источники.

Для источников win2day и GitHub справа отображается исходный логотип веб-сайта, выбранный по URL-адресу. Неизвестные поставщики не отображают логотип. Если локальный образ не читается (L001), загрузка остается доступной; восстановите соответствующий образ в resources/site-logos из пакета приложения.

Общий → Обновление и проверка данных сочетает в себе загрузку новых данных, проверку целостности базы данных и создание диагностического отчета. Отчеты автоматически сохраняются под именем logs/ с отметкой времени; результат показывает их местоположение. Отдельные ошибки не препятствуют последующим проверкам. Отмена останавливает рабочий процесс. При наличии ошибок записи (L001) проверьте разрешения и свободное место в папке журналов.

Все четыре шага видны с самого начала, каждый со своим статусом. Подробности загрузки в реальном времени приведены ниже. Флажок отображается только после успешного завершения этого шага; шаг диагностики также требует сохранения отчета.

Комбинированный рабочий процесс начинается с «Проверки источников», проверяя доступность и структуру данных включенных источников. Далее следует поиск данных, проверка базы данных и диагностический отчет. Все четыре шага имеют собственную строку состояния. Сбои источника отображаются в результатах и ​​отчете; последующие проверки продолжают выполняться.
